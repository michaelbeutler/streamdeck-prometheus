Prometheus Endpoint
The URL of your Prometheus server including the protocol and port.
Example: https://prometheus.example.com:9090/
Prometheus Query (PromQL)
Enter a valid PromQL query that returns a single numeric value.
Example: node_memory_MemAvailable_bytes / 1024 / 1024 / 1024
Unit/Suffix
Optional unit or suffix to display after the metric value.
Examples: MB, GB, °C, %, req/s
Current Value
Last retrieved value from Prometheus (read-only).
Last Updated
Timestamp of the last successful update (read-only).
